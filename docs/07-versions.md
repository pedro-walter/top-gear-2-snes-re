# USA / Europe / Japan differences

* The three ROMs share the same code base; routines move a little. `tools/portsyms.py USA.asm TARGET.asm symbols.txt` ports named routines by signature
  (first 14 instructions, branch targets and absolute operands masked); `disasm/annot_eur|jpn/symbols.txt` are its output (6 of 15 symbols were ambiguous/unmatched and are marked `# UNMATCHED`).
  WRAM layout is the same in all three (`ram.txt` copied, and the password test below reads the same addresses).
* Key routine addresses (signature matched; `-` = not matched, usually because the first instructions differ):

| routine | USA | EUR | JPN |
|---|---|---|---|
| ai_walker (per-car update loop) | 00:D84B | 00:D8EB | 00:D8EB |
| ai_setup (per-race AI init) | 00:D1D4 | 00:D274 | 00:D274 |
| player_physics | 00:8A41 | 00:8A42 | 00:8A42 |
| track_number (`$0108`) | 00:CD09 | 00:CD92 | 00:CD92 |
| password_validate | 1F:D4B3 | 1F:D6AB | 1F:D922 |
| password_checksum | 1F:D74F | 1F:D947 | 1F:DBBE |
| password "end" copy | 1F:CFB9 | 1F:D157 | 1F:D3CE |
| mixed_radix_div | 1F:D887 | 1F:DA7F | 1F:DCF6 |
| rng | 01:E25B | - | 01:E28E |

* **Passwords are interchangeable between versions** (verified): a password generated by `tools/password.py` is accepted by the USA, Europe and Japan ROMs
  (country 9, difficulty 2, engine level 3 all loaded), using `TG_PW_PC=0x9FD157` (EUR) / `0x9FD3CE` (JPN) for `scripts/pwtest.lua`.
* The EUR password screen font renders `( ) < >` as `[ ] ¢ +`-like glyphs; the alphabet order is unchanged.
* Europe runs at 50 Hz and shows km/h; Japan has the same menus as Europe (`--preset race` differs from USA only in menu navigation).
